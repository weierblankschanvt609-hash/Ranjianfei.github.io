Dobot AI Center

毕业设计：基于 Python 的机器人多模态中控与设备通信系统

项目目标

通过网页、文本或语音下发自然语言指令，统一控制机械臂与工业视觉端。

技术栈

Python · FastAPI · WebSocket · asyncio · threading · TCP Socket · Vosk · NumPy · SciPy

开发方式

Gemini 辅助代码实现；本人围绕需求拆解、设备与网络参数、联调验证及问题复盘推进。

01

交互层

HTML/CSS/JavaScript 控制面板，通过 WebSocket 实时显示连接、日志与关节状态。

02

网关层

FastAPI + Uvicorn 负责 HTTP 页面、WebSocket 会话以及任务分发。

03

调度层

Session 管理机器人、视觉、语音与大模型；阻塞 I/O 通过 asyncio.to_thread 移出事件循环。

04

驱动层

RobotClient 使用 29999 / 30003 双 TCP 通道；VisionClient 连接工业视觉端。

05

感知层

Vosk 离线识别；5 阶巴特沃斯高通滤波 + RMS 能量门抑制低频噪声。

06

认知层

大模型把自然语言约束为结构化 JSON，再路由到机器人、视觉或宏动作。

关键点 A

异步与线程协作

事件循环负责 WebSocket；阻塞 Socket、模型请求和音频采集放入工作线程，避免界面“假死”。

关键点 B

协议与状态分层

UI 不直接操作设备，Session 做路由，RobotClient / VisionClient 封装协议细节，便于定位问题。

关键点 C

语音抗噪链路

16 kHz 流式采样经过高通滤波和 RMS 能量门，再送入离线识别。
